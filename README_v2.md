# ITI Companion — application

Expo / React Native source for the ITI Companion Android app. The project overview, license
and screenshots live in the repository root:

- [README.md](../README.md) — what the app is, privacy, support, license
- [docs/PROJECT_MAP.md](../docs/PROJECT_MAP.md) — file map, CSS selectors, safe-edit rules
- [docs/PRIVACY.md](../docs/PRIVACY.md) — privacy policy template

## Requirements

- Node.js 20+ and npm
- Android 8+ device with Expo Go (UI preview) or an emulator
- EAS account for cloud APK builds; JDK 17 + Android SDK 37 (build-tools 37, NDK
  27.1.12297006) for local builds

## Run

```bash
cd app
npm install            # add --legacy-peer-deps if npm reports a peer conflict
npx expo start
```

On Windows, if PowerShell blocks `npx`, use `cmd /c "npx expo start"`.

Changes to `src/lib/injected.ts` or `src/lib/mobile-css.ts` are JavaScript-only, but the
WebView keeps the old page until you reload Expo Go and reopen the Application tab.

## Verify

```bash
npx tsc --noEmit
npx expo lint
npx expo export --platform android
npx expo-doctor
```

## Build an APK

```bash
npx eas-cli@latest build -p android --profile preview
```

See [docs/BUILD_AND_MAINTAIN.md](../docs/BUILD_AND_MAINTAIN.md) for local builds, signing,
Play Store publishing and release checklists.

## Where things are

| Need                                                    | File                                                               |
| ------------------------------------------------------- | ------------------------------------------------------------------ |
| WebView host, toolbar, message bridge                   | `src/app/(tabs)/site.tsx`                                          |
| Injected script (overlay, markers, capture, login hint) | `src/lib/injected.ts`                                              |
| Phone stylesheet for the ITI site                       | `src/lib/mobile-css.ts`                                            |
| Native dashboard                                        | `src/app/(tabs)/index.tsx`                                         |
| Settings + diagnostics                                  | `src/app/settings.tsx`                                             |
| Support links                                           | `src/lib/config.ts` → `SUPPORT`, `src/components/support-card.tsx` |
| ITI URLs / API allowlist                                | `src/lib/config.ts`                                                |
| JSON → summary mapper                                   | `src/lib/adapter.ts`                                               |
| App icon + adaptive foreground                          | `assets/`, generated by `../tools/build-icons.ps1`                 |

## Cloud build vs Expo Go

Expo Go is enough for the WebView, injection and layout work. Notifications and any new native
module need a development build (`npx expo run:android`) or an EAS build. Changing
`app.json` always requires a rebuild.
